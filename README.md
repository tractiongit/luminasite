## Estrutura

`index.html` na raiz é a página atual, com CSS inline. `assets/` contém imagens e fontes; `script.js` contém o comportamento. `tailwind.css` e `styles.css` são auxiliares e não devem substituir cegamente o CSS inline. Consulte AGENTS.md antes de editar.

Scripts de download/localização, original_index.html e clone_backup são históricos. Não é necessário refazer o clone para atualizar textos ou fotos.

## Visualização

Execute nesta pasta:

```powershell
python -m http.server 8080 --bind 127.0.0.1
```

Abra http://127.0.0.1:8080/ e confira a seção alterada em desktop e celular.
